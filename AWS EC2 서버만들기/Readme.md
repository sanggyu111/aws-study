# AWS 프리 티어로 과제용 서버 만들기

## 과제
AWS 프리 티어 범위 안에서 아래 조건을 모두 만족하는 EC2 서버를 만든다.

## 조건
1. **접근 제한**: 나를 제외한 다른 사람은 서버에 접속할 수 없다.
2. **차단 기록**: 막힌 접속 시도를 로그로 남기고, 나중에 확인할 수 있다.
3. **DB 연결**: 데이터베이스를 만들고 서버와 연결한다.
4. **트래픽 규칙**: 인바운드·아웃바운드 규칙을 필요한 만큼 설정한다. 추가로 해도 상관없음
5. **Next.js 서버**: 위 조건을 지키는 서버에서 Next.js 앱을 실행한다.

## 목표
1. **네트워크 구조 이해**: VPC, EC2, 서브넷, IGW, 라우팅 테이블이 무슨 역할인지 설명
2. **보안 설절 이해**: 보안 그룹의 인바운드, 아웃바운드 규칙의 원리를 이해
3. **DB 분리 이해**: DB를 프라이빗 서브넷에 두고 서버로 거쳐서만 접근하게 하는 이유를 설명
4. **로그 기반 보안 점검**: 흐름 로그에서 반복되는 접속 시도와 포트를 집계하고, 정상/위험 신호를 판단
